# Governance Workflow Guide

## Execution Order For This Stage Instance

1. Freeze stage-local scope and runtime invariants.
2. Capture canonical baseline outputs.
3. Record zero-violation evidence.
4. Refresh canonical architecture intelligence.
5. Validate the architecture brain.
6. Execute the canonical closure sequence.

## Clean-Baseline Rule

When the canonical baseline reports zero in-scope violations, repository remediation is not authorized or required. The stage completes through evidence capture and artifact refresh only.
