## Multi-Tenant Isolation Verification

1. Use two workspaces: `workspace-a` and `workspace-b`.
2. Create test data under `workspace-a`.
3. Repeat the same read request under `workspace-b` credentials.
4. Expected: `workspace-b` must never receive `workspace-a` data.

If data leakage is observed, stop and report immediately.
