## GitHub Actions CI Validation

**.github/workflows/ui-system-lint.yml:**

```yaml
name: UI System Linting

on:
  pull_request:
    paths:
      - 'packages/ui-system/**'

jobs:
  lint:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v3

      - uses: pnpm/action-setup@v2
        with:
          version: 8

      - uses: actions/setup-node@v3
        with:
          node-version: 18
          cache: 'pnpm'

      - run: pnpm install

      - name: ESLint Check
        run: pnpm lint

      - name: Type Check
        run: pnpm type-check

      - name: Build Check
        run: pnpm build

      - name: Test Coverage
        run: pnpm test:coverage

      - name: UI System Guard Validation
        run: |
          echo "Validating shadcn-vue base usage..."
          grep -r "custom-" src/components/ && exit 1 || true
          echo "Validating no inline styles..."
          grep -r "style=" src/components/*.vue && exit 1 || true
          echo "✅ UI System Guard checks passed"
```

## Validation Gate (Pre-Commit)

**`.husky/pre-commit` hook:**

```bash
#!/bin/sh

# Check for UI system violations
echo "Running UI System Guard pre-commit validation..."

VIOLATIONS=0

# 1. Check for custom styles
if grep -r "style=" packages/ui-system/src/components/ > /dev/null 2>&1; then
  echo "❌ BLOCKED: Found inline styles (style=)."
  echo "Use class= with Tailwind utilities instead."
  VIOLATIONS=$((VIOLATIONS+1))
fi

# 2. Check for unscoped styles
if grep -E "^<style>$" packages/ui-system/src/components/*.vue > /dev/null 2>&1; then
  echo "❌ BLOCKED: Found unscoped <style> blocks."
  echo "Add 'scoped' attribute: <style scoped>"
  VIOLATIONS=$((VIOLATIONS+1))
fi

# 3. Check for custom CSS outside @apply
if grep -rP "^\s*\.[a-z].*\{$" packages/ui-system/src/ | grep -v "@apply" > /dev/null 2>&1; then
  echo "⚠️ WARNING: Found custom CSS classes (should use Tailwind @apply)"
fi

# 4. Check for console.log
if grep -r "console\\.log\\|console\\.error\\|console\\.warn" packages/ui-system/src/components/ > /dev/null 2>&1; then
  echo "❌ BLOCKED: Found console.* calls in components."
  echo "Use event emission instead (@emit)."
  VIOLATIONS=$((VIOLATIONS+1))
fi

# 5. Check for any types
if grep -r "any" packages/ui-system/src/components/ | grep -v "AllowAny" > /dev/null 2>&1; then
  echo "⚠️ WARNING: Found 'any' type usage (use strict typing)"
fi

if [ $VIOLATIONS -gt 0 ]; then
  echo ""
  echo "❌ UI SYSTEM GUARD: $VIOLATIONS violation(s) found"
  echo "Fix violations before committing"
  exit 1
fi

echo "✅ UI System Guard: All checks passed"
exit 0
```
