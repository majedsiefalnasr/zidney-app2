# validate:ai-context-fresh

## Command

```sh
bun run validate:ai-context-fresh
```

## Purpose

Checks that the AI context mini artifact (`docs/ai/context/ai-context-mini.json`) exists on disk
and was last modified within the past 24 hours. If the artifact is missing or stale, the script
exits 1 with a structured error.

## Why It Exists

AI agents depend on the `ai-context-mini.json` artifact for fast bootstrap context. A stale
artifact can cause AI agents to reason about outdated module relationships, leading to architectural
drift in generated code. This script enforces freshness as a CI gate.

## When to Run

- Before any AI-assisted development session
- In CI pipelines that run AI governance tools
- After long breaks between development sessions
- As a pre-push gate for architecture-sensitive branches

## Execution Mode

`manual` | `ci`

Exits 1 if artifact is missing or older than 24 hours.
Exits 0 if artifact exists and was modified within the last 24 hours.

## Dependencies

- `docs/ai/context/ai-context-mini.json` — generated by `bun run ai-context:generate`
- No external dependencies

## Example Usage

```sh
# Check freshness
bun run validate:ai-context-fresh

# If stale, regenerate first
bun run ai-context:refresh && bun run validate:ai-context-fresh
```

Expected output on pass:

```json
{
  "level": "info",
  "message": "AI context is fresh",
  "metadata": { "ageHours": "2.34", "maxAgeHours": 24 }
}
```

## Known Failure Modes

| Scenario                       | Exit Code | Behavior                                  |
| ------------------------------ | --------- | ----------------------------------------- |
| `ai-context-mini.json` missing | 1         | Structured error with regeneration hint   |
| Artifact older than 24h        | 1         | Structured error with `ageHours` and hint |
| Artifact fresh and valid       | 0         | Structured info with age report           |
