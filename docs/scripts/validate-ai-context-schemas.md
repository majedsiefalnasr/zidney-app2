# validate:ai-context-schemas

## Command

```sh
bun run validate:ai-context-schemas
```

## Purpose

Validates that all 5 required AI context JSON artifacts exist under `docs/ai/context/` and are
valid, parseable JSON. Exits 1 if any artifact is missing or malformed.

## Why It Exists

The AI architecture intelligence layer depends on 5 JSON files for deterministic reasoning about
the codebase. A missing or corrupt file can cause `ai-guard.ts` to report false positives,
blocking valid commits. This script provides a fast schema integrity check for the full artifact set.

## When to Run

- After running `bun run ai-context:generate`
- Before committing architecture intelligence files
- In CI before running `arch:guard` or `arch:audit`
- During incident triage when AI governance tools misbehave

## Execution Mode

`manual` | `ci`

Exits 1 if any artifact is missing or contains invalid JSON.
Exits 0 if all 5 artifacts exist and are valid JSON.

## Dependencies

The following 5 artifacts must exist under `docs/ai/context/`:

1. `ai-layer-model.json` — Architectural layer definitions
2. `ai-module-map.json` — Module-to-layer mapping
3. `ai-dependency-graph.json` — Module dependency graph
4. `ai-context-mini.json` — Lightweight bootstrap context
5. `ai-architecture-brain.json` — Full intelligence artifact

Generated by: `bun run ai-context:generate`

## Example Usage

```sh
bun run validate:ai-context-schemas
```

Expected output on pass:

```json
{
  "level": "info",
  "message": "All AI context artifacts valid",
  "metadata": { "total": 5, "passed": 5 }
}
```

## Known Failure Modes

| Scenario                  | Exit Code | Behavior                                    |
| ------------------------- | --------- | ------------------------------------------- |
| Any artifact missing      | 1         | Structured error per missing file with path |
| Any artifact invalid JSON | 1         | Structured error with parse error message   |
| All valid                 | 0         | Structured info with total/passed counts    |
