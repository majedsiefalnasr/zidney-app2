## Executive Summary

- Root `package.json` exposes **118 scripts**; workspace manifests add another **42 local lifecycle scripts**.
- Only **39 / 118** root scripts are registry-documented in `docs/scripts/SCRIPT_REGISTRY.md`.
- **31** root scripts are directly bound to GitHub workflows; those are the real "do not break" surface.

## Method

- Sources inspected: root and workspace `package.json` files, `.github/workflows/*`, `scripts/**`, `docs/**`, the generated script registry, migration map, and script validators.
- Recommendation priority: **workflows and active docs > root-script chaining > code comments/tests > historical specs**.
- Historical references under `specs/runtime/**` were treated as background context, not primary evidence that a script is still operationally needed.
